# 高専ロボコン2026 タイマー

黒背景・白文字の全画面タイマーです。画面下部に「セッティングタイム」「チーム紹介」「試合」「設定」の4ボタンを置いています。

## 操作

- **セッティングタイム**: 0:00から1:00までカウントアップして自動停止し、1:00を表示したままにします。開始時と1:00で `sounds/whistle.m4a` を鳴らします。途中でもう一度押すと停止・リセットします。
- **チーム紹介**: `sounds/before_start.m4a` を1回再生します。
- **試合**: `READY` → `5` → `4` → `3` → `2` → `1` → `START`（2秒表示）→ `0:02` から3:00までカウントアップします。試合時刻0秒はSTART表示の開始です。合図音の再生時刻は `cue-timings.json` の `play_at_elapsed_seconds` で個別に指定します。カウントダウン中にもう一度押すと中止します。終了後は再度開始できます。
- **設定**: 音量を0〜500%で調整できます。BGMをONにすると `sounds/bgm.m4a` をループ再生します。低音強化をONにすると、BGMの160 Hz以下を約250%（+8 dB）にします。

## 音声

合図音はクリック前に読み込み、Web Audio APIで再生時刻を予約します。各ファイルの再生時刻は `cue-timings.json` の `play_at_elapsed_seconds` で個別に変更できます。値はSTARTからの秒数で、マイナス値ならSTARTより前に再生します。セッティングタイムの笛は先行再生せず、開始時と1:00で鳴ります。

セッティングタイムの笛には `sounds/whistle.m4a` を使います。

## 起動

```sh
cd /home/kazu/nhk2026_timer
python3 -m http.server 9999
```

ブラウザで `http://localhost:9999/` を開きます。M4Aを読むため、`file://` で直接HTMLを開かずHTTPサーバー経由で使ってください。
